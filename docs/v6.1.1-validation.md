## Software tests

The local v6.1.1 run covers `npm run typecheck`, `npm run lint`, `npm test`, `npm run test:integration`, Python host unit tests, `npm run build` and Playwright UI E2E. The UI E2E passes on the checked-in real DGS excerpt. Full-model mapping, preflight and AC/DC solver calls were run against both local models; AC explicitly returned `NON_CONVERGED`, while DC returned `CONVERGED`.

The Windows Native Messaging full-model UI E2E also passes: it verifies the 86,479-bus AC non-convergence summary with empty numeric AC rows, runs DC and confirms the active-power result table, and captures the full-model DC screen. Full DGS UI import is available locally through `DGS_E2E_MODEL` and is not part of CI because `kontrol1/` is ignored and not committed.

The UI screenshots are created under `artifacts/ui-review/`; CI uploads them as `ui-review`. The local no-host E2E run verifies Turkish host-install guidance. A Native Messaging full-model browser run is tracked separately from the direct full-model Python adapter run.
