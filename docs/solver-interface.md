# Solver arayüzü ve sonuç kaynağı

`PowerSystemSolver.runLoadFlow(network, options)` bir `ResultSet` döndürür. Yapı motor adı/sürümü, model kimliği ve SHA-256 hash'i, zaman, topoloji, elektriksel kapsam, yakınsama, doğrulama, uyarılar ve ekipman sonuç gruplarını içerir. Kalite türleri `MEASURED`, `CALCULATED`, `ESTIMATED`, `FORECAST`, `APPROXIMATE`, `REFERENCE` olarak tanımlanır.

`BrowserApproxSolver`, mevcut v5.5 yaklaşık çözücüsünü çağıran adaptördür. Eski UI ve senaryo akışı aynı worker'ı kullanmaya devam eder; hesap satırları `fromLegacyRows` ile `TRANSMISSION_REDUCED` ResultSet V2'ye aktarılır. `PandapowerSolver`, elektriksel kanonik ağı Native Messaging protokolüyle Python hosta gönderir ve typed ResultSet V2 döndürür. Host kurulmamışsa arayüzde “Kurulu değil” durumu gösterilir. İki motor sonucu ile varsa bağımsız PowerFactory referansı ayrı tutulur; otomatik `VALIDATED` etiketi üretilmez. Ayrıntılar [ResultSet V2](resultset-v2.md) ve [native messaging](native-messaging.md) belgelerindedir.
