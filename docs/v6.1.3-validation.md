## Scenario and branding

- Scenario hashes include normalized lines, switches, restored terminals and `autoRestoreTerminals`; revision is ignored. A -> B -> undo -> A returns to A's cache identity.
- Restored terminal order/duplicates/outer whitespace normalize to a stable sorted unique string list. Restored terminals make a scenario active; `autoRestoreTerminals` alone does not.
- IndexedDB stores all four semantic fields, and restore emits at most one mutation when state changes and none when state is already equivalent.
- Health statuses distinguish protocol, engine and engine-version mismatch with Turkish UI labels.
- History uses Turkish display names for engine, convergence and validation states.
- Product/manifest: `Grid Analyzer - Şebeke Analiz Sistemi`; workspace and sidepanel use `Grid Analyzer` / `Şebeke Analiz Sistemi`.
- PNG family: `ga-16.png`, `ga-32.png`, `ga-48.png`, `ga-128.png`, `ga-256.png`, `ga-512.png`; build validated all manifest icon dimensions. Screenshot review also contains `branding-16.png`, `branding-32.png`, `branding-48.png`, `branding-128.png`, `header-branding.png`, `sidepanel-branding.png` and `analysis-branding.png`.
